# 1 系统概述

## 1.1 现状描述

随着考研、考证与终身学习需求的增长，高校图书馆与付费自习室面临持续的"一座难求"。对某高校图书馆的实地调研与访谈显示，传统自习室管理存在五个突出问题：

1. **信息不透明**：学生无法提前获知空位分布，"到馆找座"平均耗时 10 分钟以上，高峰期更甚；
2. **占座严重**：以物品占座造成"名义占用、实际闲置"，真实利用率被进一步压低；
3. **爽约无成本**：口头预约或简单登记后不到场无任何约束，座位被无效锁定整个时段；
4. **管理粗放**：管理员缺乏数据支撑，无法量化各时段、各区域的利用情况，排班与开放决策凭经验；
5. **分配低效**：高峰期人工引导排队秩序混乱，体验差且易生纠纷。

## 1.2 系统目标

本系统定位为"面向共享自习室的一站式座位预约与运营平台"，总目标是将座位资源**在线化、公平化、数据化**。分解为七个可度量目标（G1~G7）：在线预约、智能分配、全生命周期管理、信用治理、满座候补、数据可视化、消息通知（详见《需求规格说明书》2.1 节）。

## 1.3 系统开发方法

- **分析与设计方法**：面向对象分析与设计（OOA/OOD），以用例驱动需求、以领域模型驱动设计，产出用例图、类图、ER 图、状态图、时序图、数据流图等全套 UML/结构化模型；
- **过程模型**：增量模型。按"基础设施 → 认证 → 资源管理 → 预约核心 → 智能分配 → 治理机制（信用/候补/通知）→ 统计分析 → 前端集成"的顺序分八个增量交付，每个增量均可运行、可验证；
- **工程实践**：Git 分支协作（feature 分支 + 组长审查合并）、GitHub Actions 持续集成、表驱动单元测试、迁移脚本管理数据库演进。

# 2 系统分析

## 2.1 系统需求

**功能性需求**（FR-01~FR-10，完整描述见《需求规格说明书》第 4 章）：

| 编号 | 需求 | 类型 |
| --- | --- | --- |
| FR-01/02 | 注册、登录（JWT 会话） | 核心 |
| FR-03 | 房间/座位增删改查与批量生成 | 核心 |
| FR-04 | 座位平面图在线选座（冲突检测） | 核心 |
| FR-05 | 智能自动分配（偏好加权评分） | 核心 |
| FR-06 | 预约全生命周期（签到/离开/返回/签退/违约） | 核心 |
| FR-07 | 信用分体系 | 扩展 |
| FR-08 | 满座候补与自动递补 | 扩展 |
| FR-09 | 消息通知中心 | 扩展 |
| FR-10 | 热力图与统计分析 | 核心 |

**非功能性需求**：口令 bcrypt 加密存储、SQL 全参数化、RBAC 权限隔离（安全）；常规接口 P95 < 300ms（性能）；房间规模 1~30 行列可配置（适应性）；详见需求文档第 5~7 章。

## 2.5 数据字典

系统共 7 张核心表（完整字段字典见《需求规格说明书》3.4 节）：

| 表 | 中文含义 | 关键字段 | 约束要点 |
| --- | --- | --- | --- |
| users | 用户 | username/role/credit_score/credit_banned_until | 口令哈希存储；信用 0~100 |
| rooms | 自习室 | open_time/close_time/seat_rows/seat_cols | close > open；行列 1~30 |
| seats | 座位 | row_no/col_no/zone/has_power/near_window/status | 房间内座位号与坐标唯一 |

| credit_logs | 信用流水 | delta/reason/reservation_id | 每次变动可追溯 |
| waitlist | 候补 | 房间/时段/偏好/status | 按 created_at 排队 |
| notifications | 通知 | type/title/is_read | 六类事件枚举 |

## 2.6 系统测试计划

采用"三层测试"策略：

| 层次 | 对象 | 方法 | 通过标准 |
| --- | --- | --- | --- |
| 单元测试 | 评分算法、时段校验 | 表驱动 Go test（TC-V/TC-A 系列） | 全部断言通过 |
| 接口测试 | 全部 REST 端点 | curl 冒烟脚本（正向/越权/冲突/边界） | 响应码与语义一致 |
| 端到端测试 | 核心业务闭环 | 真实浏览器走查 + 调度器实测 | 场景完整达成 |

模块级测试要点分布于《详细设计说明书》各模块"测试要点"栏；测试结果见本报告 4.3/4.4 节。
