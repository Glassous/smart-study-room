# 智能共享自习室预约系统文档口径

本文件记录课程文档定稿时采用的项目事实。课程设计计划周期为 2026 年 9 月 1 日至 9 月 15 日，采用面向对象分析与设计方法，交付可运行系统、需求分析、概要设计、详细设计、开发进度日志和课程设计报告。

## 技术栈

后端采用 Go 1.27、Gin 1.12.0、pgx 5.10.0、golang-jwt 5.3.1、go-redis 9.22.0 与 bcrypt；主数据存储为 PostgreSQL 18，Redis 7 用于缓存、限流、JWT 注销黑名单和分布式协调。前端采用 Vue 3.5.42、Vite 8.2.2、Vue Router 5.3.0、Pinia 4.0.3、Element Plus 2.14.5、Axios 1.20.0、ECharts 6.1.0 和 GSAP 3.15.0。系统通过 Docker Compose 编排 PostgreSQL、Redis 和后端服务。

## 功能范围

- 身份鉴别、JWT 会话与学生/管理员权限控制。
- 房间和座位维护、按时段选座、手动预约与智能自动分配。
- 签到、临时离开、返回、签退、取消和后台超时处理。
- 信用分、候补递补、站内通知、座位热力图和运营统计。

## 验证口径

本次文档更新已确认后端现有自动化测试通过、前端生产构建通过。接口、并发与性能测试尚需在完整 Docker Compose 环境复测，相关指标不得写成已验证结果。Redis 启动连接失败时系统可使用 PostgreSQL 运行；运行期的缓存、锁、认证注销和调度任务具有不同失败行为，详见概要设计和详细设计。
